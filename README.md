# ai_tractora Next.js Prototype

Демо-прототип отечественной платформы для конструкторских бюро, инженерных команд и промышленных предприятий, которая объединяет подготовку конструкторской документации, системы поддержки принятия решений, управленческий учет НИОКР и цифровую упаковку проектов под финансирование в едином цифровом контуре.
